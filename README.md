# KI-Assistent-f-r-Kundenservice
Das Projekt „KI im Unternehmen einführen” begleitet eine Firma  bei der Einführung eines KI-Assistenten für den internen IT-Support.  Ausgangslage: Täglich gehen 145 Anfragen ein, 61 % davon sind Standardfälle. Die erste Reaktion dauert im Median 3 Std. 20 Min., 18 % der Tickets werden falsch zugeordnet, und nur 64 % sind vollständig dokumentiert.
